## 重点
### 切片len和cap的变化规律
- 切片的长度公式是 结束索引 - 开始索引
- 切片的容量 = 原切片的容量 - 切片的开始索引

### 字符串长度和字符串循环次数
- len()函数算的是字节数，英文字符和标点每个占1个字节，中文字符占3个字节
- for range 循环遍历字符串时，默认是按字符来解码遍历的

### 函数内外数组的区别
- 当调用一个函数的时候，函数的每个调用参数将会被赋值给函数内部的参数变量，所以函数参数变量接收的是一个复制的副本，并不是原始调用的变量。因为函数参数传递的机制导致传递大的数组类型将是低效的，并且对数组参数的任何的修改都是发生在复制的数组上，并不能直接修改调用时原始的数组变量
- 因为slice值包含指向第一个slice元素的指针，因此向函数传递slice将允许在函数内部修改底层数组的元素。换句话说，复制一个slice只是对底层的数组创建了一个新的slice别名（§2.3.2）
- 所以使用指针或者切片
```
func zero(ptr [32]byte){
	*ptr = [32]byte{}
}
```

```
// reverse reverses a slice of ints in place.
func reverse(s []int) {
    for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
        s[i], s[j] = s[j], s[i]
    }
}
```

```
a := [...]int{0, 1, 2, 3, 4, 5}
reverse(a[:])
fmt.Println(a) // "[5 4 3 2 1 0]"
```

## 疑惑
### 切片
一、 为什么不用数组，都用切片？（截图上半部分）

截图第一段说：数组（Array）很少用作函数参数，一般用切片（Slice）代替。

· 原因：你之前学过，Go 里传数组是值传递（整块复制）。如果数组很大，每次调函数都复制一遍，内存和性能直接爆炸。
· 切片是引用类型，传参时只传一个很小的数据结构（包含地址、长度、容量），极其轻量。

---

二、 切片的“三要素”（全图核心）

截图中间加粗的文字，请死死记住：一个切片由三部分组成：指针、长度、容量。

1. 指针（Pointer）：指向底层数组中，切片第一个元素的内存地址。（注意：它不一定指向数组的开头，就像窗户可以开在墙的中间）。
2. 长度（Length，len）：切片当前包含的元素个数。
3. 容量（Capacity，cap）：从切片指向的那个地址开始，一直到底层数组的末尾，一共有多少个元素。

---

三、 案例拆解：月份数组与重叠的切片

看截图里的代码和图：

```go
months := [...]string{1: "January", /* ... */, 12: "December"}
```

· [...] 告诉 Go 自动计算数组长度（这里是 13）。
· 因为没定义索引 0，所以索引 0 默认是空字符串 ""。
· 此时，这个底层数组的总容量是 13。

再看下面的图示：Q2 = months[4:7]

· 含义：从索引 4 开始，切到索引 7（左闭右开，不包含 7）。也就是取出了索引 4、5、6 的元素（对应 4月、5月、6月）。
· len(Q2) 是多少？
  7 - 4 = 3。包含 3 个元素。
· cap(Q2) 是多少？
  公式是：底层数组的总容量 - 切片的起始索引。即 13 - 4 = 9。
  (为什么是 9？因为从 4 月开始，往后数还有 4、5、6、7、8、9、10、11、12，一共 9 个位置可以扩充。)

再看另一个切片：summer = months[6:9]

· 取出了索引 6、7、8 的元素。
· 重点：你看图，Q2 和 summer 虽然有部分重叠（都包含了索引 6），但它们指向的是同一个底层数组（months）。

---

四、 截图中最下方文字的化简（语法糖）

文字里说了一堆省略索引的规则，直接背这个表：

· months[1:13] 等价于 months[1:] （省去结束索引，默认切到 len 结束）。
· months[:] 代表整个底层数组。
· 所以，months[:] 的 len 和 cap 都是 13。

五、 💡 考场/实战必考的“坑”（延伸于截图的隐含知识）

因为切片共享底层数组，所以会出现一个极度危险的现象：

```go
arr := [5]int{10, 20, 30, 40, 50}
s1 := arr[1:4] // s1 = [20, 30, 40]
s2 := arr[2:5] // s2 = [30, 40, 50]

s1[1] = 999 // 修改 s1 的第二个元素（即 arr 的索引 2）

fmt.Println(s2) 
// 你猜 s2 打印什么？
// 答案是 [999, 40, 50]！
// 因为 s1 和 s2 都指向同一个底层数组，修改 s1 影响了 arr 的索引2，进而影响了 s2。
```

牢记：在 Go 里，切片操作 s[a:b] 绝对不会复制数据。如果你想要一份独立的拷贝，必须用内置函数 copy(dest, src)。

### []byte 
拆解 []byte

· byte：它其实是 uint8 的别名（无符号 8 位整数，范围是 0~255）。在计算机底层，1 个 byte 就代表 1 个字节，可以存一个英文字母或 ASCII 码。
· []：你上一题刚学过，这就是切片的语法。
· 合起来：[]byte 就是一个元素类型为 byte 的动态数组（切片）。

在 Python 里，它完美对应 bytes 或者 bytearray 类型（比如 b"hello"）。
