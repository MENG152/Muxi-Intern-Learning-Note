

1. 标题 (Headings)

使用 # 号表示标题，1个 # 是一级标题，6个 # 是六级标题。注意 # 后面必须加一个空格。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

2. 强调 (Emphasis)

这是你之前踩过坑的地方，注意符号的闭合。

· 斜体：用单星号或单下划线包裹 *斜体* 或 _斜体_
· 粗体：用双星号或双下划线包裹 **粗体** 或 __粗体__
· 粗斜体：用三星号包裹 ***粗斜体***
· 删除线：用双波浪线包裹 ~~删除线~~

3. 列表 (Lists)

· 无序列表：使用 -、* 或 + 加空格。
· 有序列表：使用数字加 . 再加空格（如 1. ）。
· 嵌套：在子列表前按 Tab 键缩进。

```markdown
- 第一项
  - 子项（按 Tab 缩进）
- 第二项

1. 第一步
2. 第二步
```

4. 代码与转义 (Code & Escaping)

· 行内代码：用反引号包裹（键盘左上角 Esc 下方那个键，必须是英文），如  `code` 。
· 代码块：用三个反引号包裹，并可在开头标明语言以获取高亮。
  ```markdown
  ```go
  fmt.Println("Hello")
  ```
  ```
  ```
  
· 转义字符：如果你想打出具有特殊格式意义的符号（如 *、#、_、\），在它们前面加一个反斜杠 \。例如：\* 会显示为 *。

5. 链接与图片 (Links & Images)

通用语法（括号加中括号）：

· 链接：[显示的文字](网址)
  · 例如：[百度](https://www.baidu.com)
· 图片：前面加个感叹号 !，![图片描述](图片网址或路径)
  · 例如：![风景照](https://example.com/pic.jpg)

(注：在 Obsidian 中，你还可以使用更强大的 [[双链]] 和 ![[图片]] 语法。)

6. 引用块 (Blockquotes)

使用 > 加空格，常用于引用别人的话。

```markdown
> 这是一段引用。
> 可以换行继续写。
```

7. 表格 (Tables)

使用 | 分隔列，使用 - 分隔表头和数据，用 : 控制对齐方式。

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| 内容1 | 内容2 | 内容3 |
```

(注意：表格里的内容不能直接换行，如果想在表格里打 |，需要用 \| 转义)

8. 分割线 (Horizontal Rules)

在单独的一行输入三个或以上的 ---、*** 或 ___。

```markdown
---
```

9. 任务列表 (Task Lists)

这是 GitHub 风格的扩展语法，在列表符号后加上 [ ] 或 [x]（中括号里要有空格）。

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
```
